# Atakan Güdüllüoğlu

MSc student in AI and Automation at University West (Högskolan Väst) in
Trollhättan, Sweden. BSc in Electrical and Electronics Engineering from
Başkent University.

I work mostly on computer vision and getting it to drive real hardware:
robots, PLCs, embedded boards and simulators.

## Projects

- **[beamng-autopilot](https://github.com/atakangudulluogluhv/beamng-autopilot)**
  Lane keeping and adaptive cruise control in the BeamNG.tech simulator.
  Classic lane detection and a DAVE-2 CNN are blended by lane confidence;
  YOLOv8 and a depth camera handle the car in front.
- **[elevator-plc-agents](https://github.com/atakangudulluogluhv/elevator-plc-agents)**
  TwinCAT 3 elevator controlled from Python over ADS, with a small neural
  network for door decisions and a deterministic safety layer that checks
  every command.
- **[gold-forecast-panel](https://github.com/atakangudulluogluhv/gold-forecast-panel)**
  Gold price forecasting with walk-forward validation. It measures how good
  its own forecast is and shows on screen when it has no edge.
- **[Sensor-Calibration-AI-M5Stick](https://github.com/atakangudulluogluhv/Sensor-Calibration-AI-M5Stick)**
  Sensor drift calibration trained and run on an ESP32, with a model
  comparison in [Sensor-Calibration-AI-HV](https://github.com/atakangudulluogluhv/Sensor-Calibration-AI-HV).
- **[multi-agent-dev-assistant](https://github.com/atakangudulluogluhv/multi-agent-dev-assistant)**
  Several LLM agents run in parallel on one question, with rate limiting and retries.
